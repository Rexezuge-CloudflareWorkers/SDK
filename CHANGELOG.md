# Changelog

All notable changes to `@rexezuge/*` packages are documented here. Packages are
versioned in lockstep via Changesets (see `.changeset/`). Per-package
`CHANGELOG.md` files are generated by `changeset version`; this file stays the
curated overview.

## Unreleased

### `@rexezuge/web`

- **Nine more components converged** from the family's copies: `AppPage`,
  `PageHeaderCard`, `ContextBar`, `Unauthorized`, `NoticeBar`, `LanguageSelector`,
  `RefreshButton`, `ReadOnlyField`, `TypeToConfirmModal`, plus the
  `useCopyToClipboard` hook three copies had inlined.
- **`lucide-react` is a peer.** Three components need glyphs; reimplementing icon
  path data would fork lucide's artwork. Labels stay props — nothing here calls
  `useTranslation`.
- **`codemods/` can migrate them.** A new relative-import transform, because
  consumers never import their own web app by package name.
- Two defects fixed from the copies: `ReadOnlyField`'s missing `htmlFor` (the
  value input had no accessible name) and `Unauthorized`'s untestable hard-coded
  navigation.

### Earlier in this cycle

Nine packages now, not eight.

- **`@rexezuge/http`** (new) — the family's HTTP layer: `rateLimit`,
  `securityHeaders`, `accessAuth`, `ErrorMapper`, `routeBase`. Converged from
  four copies each in Durable-DAV, Durable-DAV-Router, Edge-Git and Edge-Sonic.
  This is the one package in the kit that depends on `hono`/`chanfana`; the
  other eight stay framework-free so a repo can adopt the core without adopting
  a web framework.
- **`@rexezuge/runtime`** — `AbstractScheduledTask` and `TaskRegistry`, from the
  seven copies that ranged from 13 to 103 lines. The run recorder is a port, so
  `runtime` keeps no D1 dependency.
- **`@rexezuge/shared`** — OAuth2 PKCE and `state` helpers, from the
  byte-identical pair in Mail-Meow and Mail-Otter.
- **`@rexezuge/web`** — `ModalShell`, `ConfirmDeleteModal`, `LoadingSpinner`,
  `EmptyState`. Labels are props rather than `useTranslation`, so adopting them
  requires neither a translation library nor an icon set.
- **`@rexezuge/d1` / `@rexezuge/identity`** — an absent row is `null`, matching
  `D1Result.first()`, `KVNamespace.get()` and every service above them.
- **`@rexezuge/shared`** — `CursorCodec.decodeOrThrow` answers "malformed" only;
  absence is `decode`'s job and the caller's decision.
- **`codemods`** — `adopt.ts` implements `--remove-packages` (it was documented
  as step 3 and read `void removePackages;`), and `flagValue` no longer returns
  the positional root as the scope when `--scope` is missing.
- **`codemods`** — `adopt.ts` takes `--rules <file>`, merging operator-supplied
  departures over the shipped tables per-row (the documented override escape
  hatch now exists); identity renames are member-scoped, so `resolveUserId`
  imports no longer rewrite onto a symbol the kit does not export; the
  `Provider`/`ServiceContext` → `RequestScope` rows and the `shared/utils/*`
  rewrite tail are removed for the same reason.

## 1.0.0

Initial release of the converged kit, distilled from eight worker monorepos
(AWS-AccessBridge, CalDAV-Bridge, Durable-DAV, Durable-DAV-Router, Edge-Git,
Edge-Sonic, Mail-Meow, Mail-Otter):

- **`@rexezuge/errors`** — catalog-driven error taxonomy. Per-status classes are
  derived from a single `CATALOG` table (no drift between status, code, and
  default message possible). `ServiceError` carries `status`, `type`,
  `retryable`, `expose`, and `cause` as public fields. `RetryableError` /
  `NonRetryableError` markers and `ServiceError.from()` / `toResponse()`
  normalize error handling at boundaries.
- **`@rexezuge/runtime`** — DI container with branded tokens, request scope,
  `AppConfiguration` with `EnvParser`, `AbstractEntrypointWorker` /
  `AbstractDurableObjectWorker` / `AbstractQueueWorker` / `AbstractWorkflowWorker`,
  logger, `KvCache`.
- **`@rexezuge/shared`** — pure utilities that were duplicated across repos:
  UUID, Timestamp, Crypto, Base64 (single non-doubling codec), `CursorCodec`,
  SSRF policy, `PasswordFingerprint`, `SubrequestMeter`, and friends.
- **`@rexezuge/i18n`** — backend string bundle with the shared 12-locale table.
- **`@rexezuge/d1`** — one retry engine (exponential backoff, dual failure
  shapes), error classifier with retryable-first ordering, straight-line
  `BaseDAO` (`run`/`first`/`all`/`count`/`batch`/`deleteOlderThan`), AES-GCM.
  Cursor pagination and subrequest budgeting moved out of the DAO into a
  utility and an injectable port respectively.
- **`@rexezuge/identity`** — `UserIdentityService` carrying the strictest
  invariants found in the family (frozen email anchor, verified-address
  semantics), canonical `users`/`user_emails` migrations, upgrade test fixture.
- **`@rexezuge/web`** — themed UI primitives and normalized React hooks.
- **`@rexezuge/tooling`** — ESLint config factory, vitest/vite bases, repo
  scripts (god-files guard, spa-shell verification, wrangler config, locale and
  migration validation), GitHub Actions workflow templates.
